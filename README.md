### 🌐 Descripción del Backend
Servicio backend encargado de centralizar la información académica, procesar la sincronización de asistencias de la app móvil y alimentar el portal web administrativo.

* **API REST:** Endpoints para alumnos, cursos, sesiones y sincronización en lote de asistencias.
* **Base de Datos Central:** PostgreSQL con esquema relacional, llaves foráneas y prevención de registros duplicados.
* **Web Admin:** Panel web integrado para visualización de métricas, asistencias y reportes.

### 🛠️ Tecnologías Utilizadas
* Node.js & Express
* PostgreSQL (`pg.Pool`)
* CORS & Dotenv
* Portal Web SPA (HTML5, CSS3, JavaScript)
